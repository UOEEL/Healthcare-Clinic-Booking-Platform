# 🏥 Healthcare Clinic Booking Platform — Manual Testing Project

## 🔗 Target Application

**CareNest Clinic Booking Platform**

[Live Application](https://ahmedsayed28.github.io/Clinic-Booking-App/index.html)

---

## 📌 Project Overview

A Manual Software Testing project focused on validating the functionality, usability, and reliability of a Healthcare Clinic Booking Platform.

The project was carried out as part of the **Digital Egypt Pioneers Initiative (DEPI) — Software Testing Track**, following the principles of the **Software Testing Life Cycle (STLC)**.

The main goal was to identify defects, verify system requirements, and ensure that the platform works correctly across its main user workflows.

---

## 🎯 Scope of Testing

The testing activities covered the following core modules:

* **Patient Registration & Login**
* **Doctor Search & Filtering**
* **Doctor Profile & Schedule**
* **Appointment Booking**
* **Payment**
* **Promo Codes**
* **Appointment Cancellation**
* **Patient Dashboard**

Testing focused on validating both positive and negative scenarios and ensuring that the system behaves as expected according to the defined requirements.

---

## 🧪 Testing Activities

The project included:

* Functional Testing
* UI Testing
* Validation Testing
* Positive & Negative Testing
* Boundary Value Analysis (BVA)
* Equivalence Partitioning (EP)
* Test Case Design & Execution
* Bug Identification & Reporting
* Regression Testing
* Exploratory Testing

---

## 🐞 Defect Management

During test execution, several defects were identified and documented.

Each bug report includes relevant information such as:

* Bug ID
* Bug Title
* Preconditions
* Steps to Reproduce
* Expected Result
* Actual Result
* Severity
* Priority
* Environment
* Evidence / Screenshots

Bugs were tracked using **Jira**, while the documented bug reports and supporting evidence are organized in this GitHub repository.

---

## 📊 Test Coverage

The test cases covered important user journeys, including:

* Creating and validating a patient account
* Logging in with valid and invalid credentials
* Searching for doctors
* Filtering doctors
* Viewing doctor profiles and available schedules
* Booking available appointments
* Booking for yourself or someone else
* Validating appointment information
* Applying valid and invalid promo codes
* Validating payment information
* Cancelling appointments
* Verifying appointment status in the patient dashboard
